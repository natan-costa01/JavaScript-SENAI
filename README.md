Conteúdos abordados

| Arquivo | Descrição |
|---------|-----------|
| `caseSensitive.js` | Diferenciação entre letras maiúsculas e minúsculas no JavaScript. |
| `hello.js` | Conhecimento do hello world em JavaScript |
| `let.js` | Utilização da função let para diferenciar arquivos. |
| `function_javascript.js` | Introdução à declaração e utilização de funções. |
| `literais.js` | Estudo dos valores literais e suas representações. |
| `valores.js` | Introdução aos valores e tipos de dados da linguagem. |
